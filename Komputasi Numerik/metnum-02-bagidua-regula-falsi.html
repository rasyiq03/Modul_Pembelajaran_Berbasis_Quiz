1. Rumusan masalah dan metode tertutup

Sebagian persamaan mudah diselesaikan secara analitik. Persamaan 2x − 3 = 0 selesai dengan memindahkan −3 ke ruas kanan sehingga x = 3/2, dan x2 − 4x − 5 = 0 selesai dengan pemfaktoran (x − 5)(x + 1) = 0 sehingga x = 5 atau x = −1. Namun persamaan yang muncul di sains dan rekayasa umumnya nirlanjar (non-linear) dan memuat sinus, kosinus, eksponensial, logaritma, atau polinom berderajat tinggi. Bentuk seperti itu tidak bisa dipecahkan dengan manipulasi aljabar biasa, sehingga akarnya dicari secara numerik.

2. Syarat keberadaan akar dan cara memilih selang

Metode tertutup hanya bekerja bila selang [a, b] benar-benar mengurung akar. Cara paling murah untuk memeriksanya adalah melihat tanda nilai fungsi di kedua ujung selang, karena tanda itu memberi petunjuk tentang banyaknya akar di dalamnya.

Apa arti tanda f(a) dan f(b)

  • Jika f(a)f(b) < 0, di dalam selang terdapat akar sebanyak bilangan ganjil (1, 3, 5, …).
  • Jika f(a)f(b) > 0, di dalam selang terdapat akar sebanyak bilangan genap (2, 4, …) atau tidak ada akar sama sekali.

Syarat cukup keberadaan akar

Jika f(a)f(b) < 0 dan f(x) menerus di dalam selang [a, b], maka paling sedikit terdapat satu akar f(x) = 0 di dalam selang [a, b].

Pernyataan ini disebut syarat cukup, bukan syarat perlu. Dalam logika, "jika p maka q" berarti p cukup untuk menjamin q, tetapi q tetap mungkin benar walaupun p salah. Jadi bila f(a)f(b) > 0, akar masih mungkin ada (seperti panel c di atas); kita hanya kehilangan jaminannya. Perhatikan juga kata menerus: fungsi yang putus di dalam selang bisa berganti tanda tanpa punya akar, seperti dibahas di bab 4.

3. Metode bagidua

Metode bagidua (bisection, juga disebut metode Bolzano) adalah metode tertutup paling sederhana. Misalkan selang [a, b] sudah memenuhi f(a)f(b) < 0. Pada setiap lelaran, selang dibagi dua tepat di titik tengah c sehingga terbentuk dua upaselang berukuran sama, [a, c] dan [c, b]. Upaselang yang dipertahankan adalah yang ujung-ujungnya masih berbeda tanda, karena hanya upaselang itu yang dijamin masih mengurung akar.

c = (a + b) / 2c titik tengah selang; nilai fungsi tidak ikut menentukan posisi c

Langkah 1. Siapkan selang

Tentukan a dan b lalu periksa f(a)f(b) < 0. Tanpa pemeriksaan ini, tidak ada jaminan akar berada di dalam selang.

Langkah 2. Hitung titik tengah

c = (a + b)/2, lalu hitung f(c). Satu lelaran hanya butuh satu evaluasi fungsi yang baru.

Langkah 3. Pilih upaselang

Jika f(a)f(c) < 0, akar ada di [a, c] sehingga b ← c. Jika tidak, akar ada di [c, b] sehingga a ← c.

Langkah 4. Periksa kriteria berhenti

Berhenti bila |b − a| < ε atau |f(c)| sudah sangat kecil. Kriteria |f(c)| < ε dipakai sebagai pengganti f(c) = 0 karena bilangan riil tidak tersimpan tepat di mesin.

Langkah 5. Ulangi atau umumkan hasil

Bila belum berhenti, kembali ke langkah 2 dengan selang yang baru. Bila sudah, c adalah hampiran akar.

Kriteria berhenti

Ada tiga pilihan kriteria berhenti. Pertama, lebar selang |b − a| < ε, dengan ε toleransi lebar selang yang mengurung akar. Kedua, nilai fungsi di hampiran akar sudah nol. Karena dua bilangan riil tidak dapat dibandingkan kesamaannya secara andal di komputer, f(c) = 0 diuji sebagai |f(c)| < ε dengan ε bilangan yang sangat kecil, misalnya epsilon mesin. Ketiga, galat relatif hampiran |(cbaru − clama)/cbaru| < δ.

Algoritma (Program 3.2)

procedure BagiDua(a, b: real);
{ K.Awal : f(a)*f(b) < 0;  K.Akhir : hampiran akar tercetak }
const
  epsilon1 = 0.000001;    { batas lebar selang akhir lelaran }
  epsilon2 = 0.00000001;  { bilangan yang sangat kecil, mendekati nol }
begin
  repeat
    c := (a + b)/2;            { titik tengah [a, b] }
    if f(a)*f(c) < 0 then
      b := c                   { selang baru [a, b] = [a, c] }
    else
      a := c;                  { selang baru [a, b] = [c, b] }
  until (ABS(a - b) < epsilon1) or (ABS(f(c)) < epsilon2);
  writeln('Hampiran akar = ', c:10:6);
end;

4. Analisis galat dan kasus khusus metode bagidua

Kelebihan besar metode bagidua adalah galatnya bisa dijamin sebelum lelaran dimulai. Karena lebar selang terpotong separuh setiap lelaran dan akar selalu berada di dalam selang, jarak hampiran ke akar sejati tidak pernah melebihi setengah lebar selang saat itu.

Teorema 3.1

Jika f(x) menerus di [a, b] dengan f(a)f(b) < 0, s ∈ [a, b] dengan f(s) = 0, dan cr = (ar + br)/2, maka berlaku:

|s − cr| ≤ (br − ar)/2   dan   |s − cr| ≤ (b − a)/2r+1r = 0, 1, 2, …; ar, br ujung selang pada lelaran ke-r

Buktinya sederhana: br − ar = (br−1 − ar−1)/2, sehingga setelah r kali pembagian lebarnya (b − a)/2r. Titik cr ada di tengah dan s ada di salah satu belahan, jadi jaraknya paling jauh setengah lebar itu.

Galat sebenarnya selalu di bawah batas teorema

Contoh 3.1, s = 0,605267. Galat sebenarnya kadang naik, tetapi batasnya terus turun separuh.

Berapa lelaran yang dibutuhkan?

Agar galat lebih kecil dari ε, cukup dipastikan (b − a)/2R < ε. Ambil logaritma natural pada kedua ruas:

R > [ ln(b − a) − ln(ε) ] / ln 2R jumlah lelaran (jumlah pembagian selang) yang menjamin galat hampiran kurang dari ε

Untuk Contoh 3.1, R > (ln 1 − ln 0,00001)/ln 2 = 16,60964, sehingga dibutuhkan minimal 0 lelaran (r = 0 sampai 16), sama dengan tabel lelaran di bab 3. Perhatikan bahwa rumus ini sama sekali tidak bergantung pada bentuk f(x).

5. Metode regula-falsi

Bagidua selalu berhasil, tetapi lambat karena mengabaikan informasi yang sudah dihitung, yaitu nilai f(a) dan f(b). Logikanya, bila f(a) jauh lebih dekat ke nol daripada f(b), akar tentu lebih dekat ke a daripada ke b. Metode regula-falsi (bahasa Latin, berarti metode posisi palsu atau false position method) memanfaatkan nilai itu: garis lurus ditarik dari titik (a, f(a)) ke (b, f(b)), dan titik potong garis dengan sumbu-x menjadi taksiran akar yang baru. Garis lurus itu seolah-olah menggantikan kurva dan memberikan posisi palsu dari akar.

Penurunan rumus

Titik A = (a, f(a)), B = (b, f(b)), dan C = (c, 0) terletak pada garis yang sama, sehingga gradien AB sama dengan gradien BC:

[f(b) − f(a)] / (b − a) = [f(b) − 0] / (b − c)kesamaan gradien garis AB dan BC

Selesaikan untuk c dan diperoleh rumus regula-falsi (P.3.2):

c = b − f(b)(b − a) / [f(b) − f(a)]karena f(a) dan f(b) berbeda tanda, c selalu berada di dalam selang [a, b]

Algoritma regula-falsi hampir sama dengan bagidua. Bedanya hanya pada cara menghitung c, dan kriteria berhentinya perlu ditambah pemeriksaan |f(c)| yang alasannya dijelaskan di bab 6.

procedure regula_falsi(a, b: real);
const
  epsilon1 = 0.00001;    { batas lebar selang akhir lelaran }
  epsilon2 = 0.000001;   { batas nilai |f(c)| yang dianggap nol }
begin
  repeat
    c := b - (f(b)*(b - a)/(f(b) - f(a)));
    if abs(f(c)) < epsilon2 then      { f(c) = 0, c adalah akar }
      begin a := c; b := c; end
    else if f(a)*f(c) < 0 then
      b := c                          { selang baru [a, c] }
    else
      a := c;                         { selang baru [c, b] }
  until (ABS(a - b) < epsilon1) or (ABS(f(c)) < epsilon2);
  writeln('Hampiran akar : ', c:10:6);
end;

6. Titik mandek dan regula-falsi yang diperbaiki

Secara umum regula-falsi lebih cepat konvergen daripada bagidua, tetapi pada beberapa kasus malah lebih lambat. Penyebabnya adalah kurva yang cekung (konkaf) di dalam selang. Pada kurva cekung, garis potong selalu berada di sisi yang sama terhadap kurva: selalu di atas kurva bila cekung ke atas, atau selalu di bawah kurva bila cekung ke bawah. Akibatnya c selalu jatuh di sisi akar yang sama, dan satu ujung selang tidak pernah berubah.

Titik mandek

Ujung selang yang tidak pernah berubah itu disebut titik mandek (stagnant point). Pada titik mandek, br − ar = b − ar untuk setiap r, sehingga lebar selang tidak pernah lebih kecil dari ε. Bila kriteria berhentinya hanya |b − a| < ε, program bisa berputar terus (looping). Karena itu kriteria berhenti regula-falsi harus ditambah |f(c)| < ε₂, seperti pada program di bab 5. Pada contoh ex − 5x2, kurvanya cekung ke bawah, garis potong selalu di bawah kurva, c selalu jatuh di kiri akar dengan f(c) > 0, sehingga hanya a yang bergeser dan b = 1 mandek.

Perbaikan: bagi dua nilai f di titik mandek

Regula-falsi yang diperbaiki (modified false position method) mencatat ujung mana yang tidak berubah lebih dari sekali. Nilai f di ujung yang mandek itu diganti menjadi setengah kalinya sebelum dipakai di lelaran berikutnya. Garis potong menjadi lebih landai ke arah titik mandek, sehingga c melompat ke sisi lain akar dan ujung yang mandek akhirnya ikut bergeser. Geser pembanding di bawah untuk melihat perbedaannya.

Kiri: semua garis menuju B yang sama sehingga c merayap dari kiri. Kanan: setelah f(b) dibagi dua, c1 = 0,6098 langsung melewati akar (dibuat ulang dari Gambar 3.8 dan 3.9).

procedure perbaikan_regula_falsi(a, b: real);
var FA, FB : real;
    mandek_kiri, mandek_kanan : integer;   { jumlah perulangan titik ujung }
begin
  FA := f(a); FB := f(b);
  mandek_kiri := 1; mandek_kanan := 1;
  repeat
    c := b - (FB*(b - a)/(FB - FA));
    if abs(f(c)) < epsilon2 then begin a := c; b := c; end
    else if f(a)*f(c) < 0 then begin
      b := c; FB := f(c);                  { selang baru [a, c] }
      mandek_kiri := mandek_kiri + 1; mandek_kanan := 0;
      if mandek_kiri > 1 then FA := FA/2;  { a menjadi titik mandek }
    end
    else begin
      a := c; FA := f(c);                  { selang baru [c, b] }
      mandek_kanan := mandek_kanan + 1; mandek_kiri := 0;
      if mandek_kanan > 1 then FB := FB/2; { b menjadi titik mandek }
    end;
  until (ABS(a - b) < epsilon1) or (ABS(f(c)) < epsilon2);
  writeln('Hampiran akar : ', c:10:6);
end;

Studi kasus: fraksi mol CO pada kesetimbangan kimia

Dalam suatu proses teknik kimia, campuran karbon monoksida dan oksigen mencapai kesetimbangan pada suhu 3000 K dan tekanan 5 atm. Reaksi teoretisnya adalah CO + ½O₂ ⇌ CO₂, sedangkan reaksi yang sebenarnya terjadi dapat ditulis CO + ½O₂ → x CO + ½(1 + x) O₂ + (1 − x) CO₂, dengan x fraksi mol CO yang tersisa. Persamaan kesetimbangannya:

Kp = (1 − x)(3 + x)1/2 / [ x (1 + x)1/2 p1/2 ],   0 < x < 1Kp = 3,06 tetapan kesetimbangan, p = 5 atm tekanan

Fungsi yang dicari akarnya adalah f(x) = (1 − x)(3 + x)1/2 / [x(1 + x)1/2p1/2] − Kp. Persoalan ini paling tepat diselesaikan dengan metode tertutup karena x adalah fraksi mol yang pasti terletak antara 0 dan 1. Selang [0,1; 0,9] memenuhi syarat cukup karena f(0,1) = 3,696815 dan f(0,9) = −2,988809, dan setiap hampiran c dijamin tetap di dalam rentang yang bermakna secara fisik.
