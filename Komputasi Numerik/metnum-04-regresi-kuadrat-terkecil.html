Garis terbaik bukan yang melewati semua titik, tetapi yang galat kuadratnya paling kecil

Data eksperimen selalu mengandung derau, sehingga memaksa kurva melewati setiap titik justru menyesatkan. Materi ini membahas regresi kuadrat terkecil: regresi linier sederhana, polinomial dengan persamaan normal matriks, linierisasi model nonlinier, regresi linier berganda, dan cara menilai kebaikan model lewat R², RMSE, serta analisis residual. Setelah selesai membaca, uji pemahamanmu lewat kuis di tab Kuis.

1. Interpolasi, regresi, dan prinsip kuadrat terkecil

Ada dua cara mencocokkan kurva (curve fitting) pada sekumpulan titik (x₁, y₁), (x₂, y₂), …, (xn, yn). Interpolasi memaksa kurva melewati setiap titik tanpa galat. Cara ini tepat bila datanya teliti, misalnya tabel fungsi matematika. Data eksperimen tidak seperti itu: setiap pengukuran membawa derau (noise), sehingga kurva yang melewati semua titik ikut meliuk mengikuti derau. Regresi mengambil sikap lain: kurva cukup mengikuti tren data, dan selisih antara data dan kurva diterima sebagai galat yang harus dibuat sekecil mungkin.

Kriteria kuadrat terkecil

Untuk model garis lurus y = a₀ + a₁x, residual titik ke-i adalah ei = yi − (a₀ + a₁xi). Kriteria kuadrat terkecil (least squares criterion) memilih a₀ dan a₁ yang meminimalkan jumlah kuadrat residual:

Sr = Σ ei² = Σ [yi − (a₀ + a₁xi)]²(1) jumlah dari i = 1 sampai n; kuadrat membuat residual positif dan negatif sama-sama dihitung
Kriteria yang mungkinKelemahan atau keunggulan
Minimalkan ΣeiResidual positif dan negatif saling menghapus; banyak garis berbeda menghasilkan Σei = 0
Minimalkan Σ|ei| (norma-L1)Kebal terhadap pencilan, tetapi tidak punya rumus tertutup dan solusinya bisa tidak tunggal
Minimalkan Σei² (norma-L2, kuadrat terkecil)Solusi tunggal dengan rumus tertutup dari turunan parsial; tetapi peka terhadap pencilan

Analogi pegas. Bayangkan setiap titik data dihubungkan ke sebuah batang kaku oleh pegas tegak. Energi pegas sebanding dengan kuadrat panjang tarikannya. Batang akan diam di posisi yang membuat total energi semua pegas paling kecil: itulah garis kuadrat terkecil. Satu titik yang sangat jauh menarik pegasnya kuat sekali, sehingga batang ikut miring ke arahnya.

2. Regresi linier sederhana

Nilai a₀ dan a₁ yang meminimalkan Sr diperoleh dengan menyamakan turunan parsial Sr terhadap setiap parameter dengan nol.

∂Sr/∂a₀ = −2 Σ(yi − a₀ − a₁xi) = 0   ⇒   n a₀ + a₁ Σxi = Σyi(2) persamaan normal pertama
∂Sr/∂a₁ = −2 Σxi(yi − a₀ − a₁xi) = 0   ⇒   a₀ Σxi + a₁ Σxi² = Σxiyi(3) persamaan normal kedua

Dua persamaan linier itu diselesaikan untuk kemiringan dan intersep:

a₁ = [n Σxiyi − Σxi Σyi] / [n Σxi² − (Σxi)²],   a₀ = ȳ − a₁x̄(4) garis regresi selalu melewati titik pusat data (x̄, ȳ)

Persamaan normal pertama juga berarti Σei = 0: pada model yang memuat intersep, jumlah residualnya tepat nol, sehingga rata-rata residualnya juga nol.

3. Mengukur kebaikan model dan membaca residual

Setelah garis diperoleh, pertanyaan berikutnya adalah seberapa baik garis itu mewakili data. Dua jumlah kuadrat menjadi dasarnya: St mengukur sebaran data di sekitar rata-ratanya (tanpa model), dan Sr mengukur sebaran data di sekitar model.

St = Σ(yi − ȳ)²,   R² = 1 − Sr/St,   sy/x = √[Sr/(n − 2)]R² proporsi variabilitas yang dijelaskan model (0 ≤ R² ≤ 1); sy/x galat standar estimasi

Contoh 1.2 dan 1.5: Sr, St, R², dan sy/x uji tarik

Dari tabel Contoh 1.1, residualnya −0,4; 1,6; −2,4; 1,6; −0,4 sehingga Sr = 11,20. Simpangan terhadap rata-rata 210,4 memberi St = 19712,16 + 4678,56 + 5,76 + 5126,56 + 19488,16 = 49011,20. Jadi R² = 1 − 11,20/49011,20 = 0,999771: model linier menjelaskan 99,98% variabilitas tegangan. Dua parameter sudah ditaksir dari 5 titik, sehingga derajat kebebasan yang tersisa n − 2 = 3, dan sy/x = √(11,20/3) = 1,932 MPa: data tersebar sekitar ±1,93 MPa di sekitar garis.

4. Regresi polinomial dan persamaan normal matriks

Hubungan yang melengkung dapat dimodelkan dengan polinomial derajat m:

y = a₀ + a₁x + a₂x² + … + amxm + e(5) kurvanya melengkung terhadap x, tetapi tetap linier terhadap parameter a

Karena model linier terhadap parameternya, seluruh n persamaan yi ≈ a₀ + a₁xi + … + amxim dapat ditulis sebagai sistem matriks y ≈ Xa dengan matriks desain X berukuran n × (m + 1), baris ke-i berisi [1, xi, xi², …, xim]. Meminimalkan Sr = ‖y − Xa‖² memberi sistem persamaan normal:

(XTX) a = XTy   ⇔   a = (XTX)−1 XTy(7) elemen (XTX)jk = Σxij+k dan (XTy)j = Σxijyi, untuk j, k = 0, 1, …, m

Untuk m = 1, sistem ini persis sama dengan persamaan normal (2) dan (3) di bab 2.

Contoh 2.1 dan 2.2: regresi kuadratik pada (0; 1), (1; 1,8), (2; 1,3), (3; 2,5), (4; 6,3)

Jumlahan yang diperlukan: n = 5, Σx = 10, Σx² = 30, Σx³ = 100, Σx⁴ = 354, Σy = 12,9, Σxy = 37,1, dan Σx²y = 130,3. Sistem normalnya:

Contoh 2.3: R² terkoreksi untuk mencegah overfitting

Menambah suku polinomial tidak pernah menaikkan Sr, sehingga R² selalu naik walaupun suku tambahan hanya mengikuti derau. R² terkoreksi (adjusted) membagi setiap jumlah kuadrat dengan derajat kebebasannya:

R²adj = 1 − [Sr/(n − m − 1)] / [St/(n − 1)]m derajat polinomial (atau banyaknya prediktor); n − m − 1 derajat kebebasan residual

Contoh: n = 6 dan St = 100. Model linier dengan Sr = 15 memberi R² = 0,85 dan R²adj = 1 − (15/4)/(100/5) = 0,8125. Polinomial derajat 4 dengan Sr = 10 tampak lebih baik (R² = 0,90), tetapi R²adj = 1 − (10/1)/(100/5) = 0,50. Penurunan tajam itu tanda overfitting: hampir semua derajat kebebasan habis untuk mengikuti derau. Pada data Contoh 2.1:

6. Regresi linier berganda

Bila y bergantung pada beberapa prediktor, model diperluas menjadi

y = a₀ + a₁x₁ + a₂x₂ + … + apxp + e(8) p prediktor; untuk p = 2 modelnya berupa bidang di ruang tiga dimensi

Matriks desainnya berisi kolom satu dan satu kolom per prediktor, lalu parameternya diselesaikan dengan persamaan normal yang sama: (XTX)a = XTy.

Contoh 4.1: daya server terhadap utilisasi CPU dan suhu ruang

Data (x₁ = CPU %, x₂ = suhu °C, y = daya W): (20, 25, 150), (40, 25, 210), (60, 30, 290), (80, 30, 350).

XTX = 420011020012000570011057003050 , XTy = 10005680028200

Contohnya Σx₁x₂ = 20(25) + 40(25) + 60(30) + 80(30) = 5700 dan Σx₂y = 25(150) + 25(210) + 30(290) + 30(350) = 28200. Penyelesaian sistemnya memberi a₀ = −10, a₁ = 3, dan a₂ = 4, sehingga

P = −10 + 3x₁ + 4x₂keempat titik tepat berada pada bidang ini: 150, 210, 290, 350; Sr = 0

Contoh 4.2: tafsiran koefisien parsial

  • a₁ = 3 W per %. Setiap kenaikan utilisasi CPU 1% menaikkan daya 3 W bila suhu ruang dibuat tetap.
  • a₂ = 4 W per °C. Setiap kenaikan suhu ruang 1 °C menaikkan daya 4 W (kipas bekerja lebih keras) bila beban CPU tetap.
  • a₀ = −10 W. Secara matematis ini daya pada CPU 0% dan suhu 0 °C, tetapi daya negatif tidak bermakna fisik. Titik (0, 0) jauh di luar rentang data (CPU 20–80%, suhu 25–30 °C), jadi intersep hanyalah hasil ekstrapolasi.

Jangan terpukau oleh Sr = 0. Empat titik dan tiga parameter hanya menyisakan satu derajat kebebasan, jadi kecocokan sempurna di sini lebih banyak berkata tentang sedikitnya data daripada tentang kebenaran model.

Multikolinearitas dan uji signifikansi

Bila dua prediktor berkorelasi sangat tinggi, kolom-kolomnya di X hampir sejajar, det(XTX) → 0, dan varians parameter melonjak. Ukurannya adalah variance inflation factor:

VIF = 1/(1 − r₁₂²)r₁₂ korelasi antarprediktor; VIF di atas 10 dianggap berbahaya

Untuk r₁₂ = 0,99, VIF = 1/(1 − 0,9801) ≈ 50,25. Akibatnya tanda koefisien bisa terbalik secara tidak logis dan selang kepercayaannya melebar sangat besar. Signifikansi model secara keseluruhan diuji dengan statistik F (Contoh 4.4):

F = [R²/p] / [(1 − R²)/(n − p − 1)]untuk n = 30, p = 2, R² = 0,80: F = 0,40/0,007407 = 54,0, jauh di atas F0,05(2, 27) ≈ 3,35 (p ≈ 3,7 × 10⁻¹⁰)

Model permukaan respons dan pemilihan model

Model y = a₀ + a₁x₁ + a₂x₂ + a₁₂x₁x₂ + a₁₁x₁² + a₂₂x₂² (Contoh 4.5) melengkung terhadap x₁ dan x₂, tetapi tetap regresi linier karena linier terhadap seluruh parameternya. Baris matriks desainnya [1, x₁, x₂, x₁x₂, x₁², x₂²]. Untuk memilih di antara model dengan jumlah parameter berbeda, kriteria informasi Akaike menyeimbangkan kecocokan dan kerumitan:

AIC = n ln(Sr/n) + 2pp banyaknya parameter; model dengan AIC terkecil dipilih

Tahap 1: linierisasi

ln k = ln A − (Ea/R)(1/T) adalah garis lurus terhadap 1/T. Regresi linier pada kolom 1/T dan ln k memberi kemiringan −7477,9 K dan intersep 20,437, sehingga Ea = 7477,9 × 8,314 = 62,17 kJ/mol dan A = e20,437 = 7,51 × 10⁸ s⁻¹. R² pada ruang logaritma 0,9995.

Tahap 2: kuadrat terkecil nonlinier

Hasil tahap 1 dipakai sebagai tebakan awal curve_fit yang meminimalkan Σ(ki − k̂i)² di ruang asli:

import numpy as np
from scipy.optimize import curve_fit

T_exp = np.array([300, 310, 320, 330, 340, 350, 360, 370, 380], dtype=float)   # K
k_exp = np.array([0.012, 0.025, 0.052, 0.105, 0.201, 0.385, 0.710, 1.280, 2.250]) # 1/s
R_gas = 8.314

def arrhenius(T, A, Ea):
    return A * np.exp(-Ea / (R_gas * T))

popt, pcov = curve_fit(arrhenius, T_exp, k_exp, p0=[7.5e8, 62000.0])
A_opt, Ea_opt = popt
k_pred = arrhenius(T_exp, A_opt, Ea_opt)
r2 = 1 - np.sum((k_exp - k_pred)**2) / np.sum((k_exp - k_exp.mean())**2)
print(A_opt, Ea_opt / 1e3, r2)    # ≈ 2,10e9   65,26   0,99996
